📊 رابط Google Sheets العام (لكل النماذج)

ربط كل النماذج بصفحة واحدة في Google Sheets — كل طلبية تُضاف تلقائياً مع اسم النموذج.

🗑️ خطر: حذف البيانات

📊 دليل ربط Google Sheets

اتبع هذه الخطوات لربط كل نماذجك بصفحة Google Sheets واحدة تستقبل كل الطلبيات تلقائياً:

الخطوة 1 — إنشاء ملف Google Sheets
افتح Google Sheets وأنشئ ملفاً جديداً. سمّه مثلاً "طلبيات ATHER". ستصل إليه كل الطلبيات من جميع النماذج.
الخطوة 2 — فتح Apps Script
من قائمة الإضافات اختر Apps Script. ستفتح نافذة محرر الكود.
الخطوة 3 — لصق الكود
احذف كل ما في المحرر والصق هذا الكود:
function doPost(e) { try { var ss = SpreadsheetApp.getActiveSpreadsheet(); var data = JSON.parse(e.postData.contents); var formName = data['اسم النموذج'] || 'عام'; // Get or create sheet for this form var sheet = ss.getSheetByName(formName); if (!sheet) { sheet = ss.insertSheet(formName); } // Add headers if first row if (sheet.getLastRow() === 0) { sheet.appendRow(Object.keys(data)); sheet.getRange(1, 1, 1, Object.keys(data).length) .setBackground('#2D6A4F').setFontColor('#FFFFFF').setFontWeight('bold'); } sheet.appendRow(Object.values(data)); return ContentService .createTextOutput(JSON.stringify({status: 'ok'})) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService .createTextOutput(JSON.stringify({status: 'error', msg: err.toString()})) .setMimeType(ContentService.MimeType.JSON); } }
الخطوة 4 — نشر كـ Web App
اضغط نشر ← نشر كتطبيق ويب
• التنفيذ بـ: حسابك
• الوصول: أي شخص (مهم جداً)
اضغط نشر — وافق على الصلاحيات ← انسخ الرابط الناتج
الخطوة 5 — لصق الرابط في الإعدادات
اذهب إلى الإعدادات وألصق الرابط في خانة "رابط Apps Script العام". كل الطلبيات ستُضاف تلقائياً، كل نموذج في تبويب (صفحة) منفصل!
💡 ملاحظة: كل نموذج يُنشئ تلقائياً تبويباً (صفحة) خاصاً به في نفس ملف Sheets. طلبية من "نموذج الملابس" تذهب لصفحة "نموذج الملابس"، وهكذا.
